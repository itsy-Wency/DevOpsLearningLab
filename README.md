# DevOps Learning Lab — HTML/CSS/JavaScript Edition

## Files
- `index.html` — page structure
- `styles.css` — purple-pink responsive interface
- `script.js` — lessons, scenarios, command validation, terminal simulation, progress, and answer arrays

## Run
Open `index.html` in Chrome, Edge, Firefox, or another modern browser. No installation or server is required.

## Answer storage
Student submissions are stored in the JavaScript `studentAnswers` array. Completed challenges are stored in `completedChallenges`, with per-module progress represented in `state`.

Each answer record contains:
- `moduleId`
- `challengeIndex`
- `challengeTitle`
- `submittedAnswer`
- `correct`
- `submittedAt`

There is no database, backend, API, or localStorage. Since arrays exist only in the running page, submitted answers and progress are cleared when the page is refreshed or closed. This is suitable for an individual local practice activity, not centralized collection across multiple students.

## Simulator note
The terminal is a safe command simulator. It validates task-specific commands and displays simulated results. It does not execute real operating-system commands or connect to Git, GitHub, Docker, or a deployment server.


## Visual learning aids
Each module now includes a responsive SVG concept map:
- Git: working directory → staging → commit → remote
- Environment variables: one codebase with environment-specific configuration
- Deployment: build → test → staging → production, with rollback
- Docker: Dockerfile → image → containers
- CI/CD: trigger → checkout → build/test → deploy
- Production: user → application → database → backup, surrounded by operational controls
- Capstone: connected end-to-end delivery workflow

The diagrams are embedded as SVG generated by vanilla JavaScript; no image library or external asset is required.
